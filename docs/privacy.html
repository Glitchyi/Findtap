Privacy Policy

Last updated: May 8, 2026

FindTap is a browser extension that provides a keyboard-driven search palette for finding and clicking visible interactive elements on the current webpage.

FindTap does not collect, transmit, sell, or share user data.

Data Collection

FindTap does not collect:

  • Personally identifiable information
  • Health information
  • Financial or payment information
  • Authentication information
  • Personal communications
  • Location information
  • Web history
  • User activity
  • Website content

Local Processing

FindTap runs locally in the browser. When the user activates the extension, it inspects the current page locally to find visible clickable elements, render highlights, and dispatch the selected click.

This processing happens in the browser tab. Page content, page URLs, browsing history, keystrokes, clicks, and search queries are not sent to any server.

Storage

FindTap uses browser extension storage only for user preferences:

  • Maximum number of results to show
  • Whether Enter selects the top result

These settings are stored by the browser extension platform. FindTap does not use this storage for page content, URLs, browsing history, or user behavior.

Network Requests

FindTap does not make network requests. It does not use analytics, tracking pixels, beacons, remote scripts, remote styles, remote fonts, or external assets.

Remote Code

FindTap does not use remote code. All JavaScript, CSS, and extension assets are included in the extension package.

Third-Party Sharing

FindTap does not sell, transfer, or share user data with third parties.

Contact

For privacy questions, use the publisher contact email listed on the Chrome Web Store listing or open an issue in the GitHub repository: github.com/Glitchyi/Findtap/issues.
